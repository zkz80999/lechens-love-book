# From September Onward

Open `index.html` through a local web server. The book is a self-contained interactive flipbook using all 33 supplied photos.

Run: `python -m http.server 4173 --bind 0.0.0.0`

Open `http://127.0.0.1:4173` on this computer, or use this computer's Wi-Fi IP address on a phone connected to the same network.
